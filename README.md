# Akshay Kumar — Portfolio

Personal portfolio showcasing software projects, AI tools, and technical experiments. Built with semantic HTML, modern CSS, and vanilla JavaScript without framework overhead.

---

## Highlights

- **Editorial Visual System:** Curated typography paired with warm ink and terracotta tones.
- **Dark / Light Theme:** Custom theme switcher with persistent user preference storage.
- **Interactive Terminal:** Simulated live code execution with tab switching and copy affordances.
- **3D Card Tilt & Particle Canvas:** Subtle physics-based particle canvas and perspective tilt effects.
- **Interactive 3D Visualizer:** Embedded interactive canvas component.
- **Performance & Accessibility:** Zero client framework dependencies, fast load times, and `prefers-reduced-motion` compliance.

---

## Tech Stack

- **Markup:** HTML5 (Semantic architecture, Open Graph and Twitter metadata)
- **Styling:** Vanilla CSS3 (Custom design tokens, glassmorphism, fluid responsive grid)
- **Scripting:** Vanilla JavaScript (ES6+, IntersectionObserver, Canvas API)
- **Local Runtime:** Node.js (Zero-dependency preview server)

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)

### Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/akshaydoingthings/PORTFOLIO.git
   cd PORTFOLIO
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
